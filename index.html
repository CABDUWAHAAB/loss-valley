The learning loop

How one step works

The model checks its error, finds which way is worse, and moves the other way.

  1. 01

    Measure the loss

    The model makes an answer. Loss compares it with the correct answer. A lower number is better.

  2. 02

    Find the slope

    The gradient shows how the loss changes. It points toward a higher loss.

  3. 03

    Move the weight

    The model moves the other way. The learning rate decides how large the move is.

Source: Chapter 2 · “The engine of neural networks: Gradient-based optimization”.
